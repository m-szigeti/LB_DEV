Gender Based Vulnerabilities — equality-symbol proposals

Recreated from the combined ♂ / ♀ / equals mark. Red square removed; symbols sit on a transparent background (checkerboard cards). No pink. Two intensity stories: gray shade and line weight, plus a combined option that is usually easiest to read on the map.

A — Gray shades (same line weight)

Light → mid → near-black. Same stroke, so the silhouette stays identical at every class.

Medium #737373

B — Thickening lines (same dark gray)

Thin → medium → heavy. Colour stays charcoal so class is carried only by weight.

Low stroke 3.2
Medium stroke 6.5
High stroke 10.5

C — Combined (gray + weight) — extra map-ready option

Light/thin → mid → black/heavy. Usually the clearest Low–Medium–High step at marker size.

Low light + thin
Medium mid gray + medium
High black + heavy
